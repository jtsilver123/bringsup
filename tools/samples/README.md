# Sample concepts for bringsup.com

The "Sample concepts" on the website are **fictional businesses** (`.example` domains, 555 phone numbers). They show the process without using a real prospect's name.

- `bakery.json`, `auto.json`, `trades.json`: inputs for `python3 tools/make_concept.py <file> out/`.
- `before.html`: the made-up "old site" for Marigold Bakery used in the homepage before/after slider.

To refresh the site images, render each sample, then save to `assets/work/`:
`<name>-full.jpg` (desktop page scaled to 1200 wide), `<name>-hero.jpg` (top 1440x900 scaled to 1200x750), `<name>-phone.jpg` (top 390x844 of the phone shot), and `bakery-before.jpg` (before.html at 1440x900, scaled to 1200x750).

Never put a real prospect's concept on the site without their written OK.
